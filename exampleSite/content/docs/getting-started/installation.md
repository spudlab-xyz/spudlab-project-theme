## Requirements

You need a current Node.js release and a terminal. Check Node.js before installing:

```sh
node --version
```

## Install the CLI

Install Canopy globally with npm:

```sh
npm install -g canopy-cli
canopy --version
```

{{< callout title="Example project" >}}
Canopy is fictional. These commands demonstrate how installation documentation appears and are not expected to download a real package.
{{< /callout >}}
